# Contribute to Cenkbot

Keep changes focused on a small, useful portfolio chatbot: clear answers, accessible integration and predictable costs.

```sh
npm install
npm run check
npm test
npm run build
```

Use offline fake providers in tests. Do not run paid model calls without an explicit budget. Never commit credentials, private portfolio documents or visitor conversations.

One model per generation, no provider race or silent fallback. Jev review and a single bounded rewrite are explicit options. Preserve unknown costs as unknown. Explain meaningful behavior changes in the changelog.

Personal benchmarks, deployment automation and maintainer agent files do not belong in the public product tree.
